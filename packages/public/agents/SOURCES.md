# Agent marks

These marks identify third-party products, not Vibe Studio. Keep their original
geometry and avoid presenting adapted UI accents as official brand guidelines.

- `codex.svg`, `claude.svg`, `gemini.svg`: OpenAI, Claude and Google Gemini paths
  from the existing `simple-icons` 15.16.0 dependency (CC0 collection). Original
  sources: https://openai.com/brand, https://claude.ai, https://gemini.google.com.
- `opencode-light.svg`, `opencode-dark.svg`: square brand assets from
  https://github.com/anomalyco/opencode/tree/dev/packages/console/app/src/asset/brand
  (MIT repository). Original geometry and light/dark fills retained.
- `oh-my-pi-light.svg`, `oh-my-pi-dark.svg`: https://github.com/can1357/oh-my-pi/blob/main/assets/icon.svg
  (MIT repository). Light variant changes only the pale Pi bars to dark for
  visibility; the orange connector and dots are preserved.
- `deepseek-harness.svg`: https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/web/public/favicon.svg
  (MIT repository). Rendered using the DeepSeek blue identity accent.

Retrieved 2026-10-16. Logos remain trademarks of their respective owners.
The shared `agent-brand.css` owns readable light/dark text and surface colors;
these are Vibe Studio presentation choices, not provider runtime settings.
