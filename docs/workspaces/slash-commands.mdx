Slash commands are shortcuts for common actions within your coding agent. Type `/` followed by a command name to run operations like compacting conversation history, initializing project documentation, or reviewing code changes.

## Using Slash Commands

To use a slash command:

1. Type `/` at the beginning of a new line in the chat input
2. A typeahead menu appears showing available commands
3. Continue typing to filter the list, or use arrow keys to navigate
4. Press **Enter** or click to select a command
5. Add any arguments after the command name (some commands accept optional parameters)
6. Send the message as normal

<Tip>
  Some commands accept optional arguments. For example, with Claude Code or
  Codex, `/compact focus on the authentication changes` will compact the
  conversation while emphasising the authentication work in the summary.
</Tip>

## Available Commands by Agent

The available slash commands depend on which coding agent you're using. Vibe Studio discovers commands from the selected agent where possible, then shows whether each command is handled by Vibe Studio, passed through to the agent, or provided by an extension such as a skill or custom command.

<Note>
  Some built-in commands that require TUI interaction (such as `/model` or
  `/theme`) are not currently supported in Vibe Studio. Only non-interactive
  commands are available.
</Note>

### Claude Code

Claude Code commands are discovered from your installed Claude Code CLI. The list can change when you update Claude Code, install skills, add project or user commands, or enable plugins. For full details, see the [built-in commands](https://code.claude.com/docs/en/interactive-mode#built-in-commands) and [skills](https://code.claude.com/docs/en/skills) documentation.

Vibe Studio labels Claude commands by support level:

| Label         | Meaning                                                                                                                                                                                   |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VK 支持`     | Vibe Studio recognises this as a product-level entry point. The first version still passes Claude commands through to Claude Code unless a Vibe Studio handler is explicitly implemented. |
| `Claude 原生` | The command is a Claude Code native command and is passed through unchanged.                                                                                                              |
| `Skill`       | The command comes from Claude Code skills and is handled by Claude Code.                                                                                                                  |
| `Custom`      | The command comes from a project command, user command, or plugin command and is handled by Claude Code.                                                                                  |
| `诊断`        | The command is diagnostic or debugging-oriented, so it is not treated as a normal product workflow.                                                                                       |
| `Fallback`    | The command comes from Vibe Studio's fallback list because live discovery did not return commands.                                                                                        |

Common Claude Code commands that Vibe Studio recognises include `/compact`, `/review`, `/security-review`, `/init`, `/context`, `/usage`, `/insights`, and `/goal`. Commands such as `/config`, `/reload-skills`, and `/team-onboarding` remain Claude-native pass-through commands.

<Warning>
  Claude Code commands may vary by CLI version. Treat the typeahead result as
  the source of truth for the selected workspace and agent.
</Warning>

### OpenAI Codex

Vibe Studio surfaces a curated subset of Codex built-in commands. For the full upstream list, see the [Codex slash commands documentation](https://developers.openai.com/codex/cli/slash-commands/).

| Command        | Description                                             |
| -------------- | ------------------------------------------------------- |
| `/compact`     | Summarize the conversation to free tokens               |
| `/review`      | Review the current changes                              |
| `/init`        | Generate an AGENTS.md scaffold in the current directory |
| `/status`      | Display session configuration and token usage           |
| `/mcp`         | List configured MCP tools                               |
| `/skills`      | Show available Codex skills                             |
| `/fast`        | Toggle or inspect fast mode                             |
| `/goal`        | Set or view the goal for a long-running task            |
| `/personality` | Choose a Codex communication style                      |

### Gemini CLI and Oh My Pi

Gemini CLI and Oh My Pi expose provider-native commands through their runtime
protocols. Vibe Studio discovers commands when the runtime supports discovery;
otherwise the command list is empty rather than copied from a different
provider.

## Command Discovery

When you select an agent, Vibe Studio automatically discovers the available slash commands. You'll see "Discovering commands..." in the typeahead while this happens.

Commands are cached per workspace and agent, so subsequent uses are instant.

<Info>
  If you add new custom commands to your agent's configuration, switch to a
  different agent and back, or create a new session to refresh the command list.
</Info>
