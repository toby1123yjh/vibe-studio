Vibe Studio gives independent developers and one-person companies a place to work with their AI agents in a browser.

Connect agents, organise project tasks and files, and build workflows that pass work between agents. Open a conversation to guide execution and review the deliverables.

Supported agents include Claude Code, Codex, Gemini CLI, Oh My Pi, OpenCode and DeepSeek Harness. Install them from the Agent Center or use existing installations on the host.

```bash
npx @toby1123yjh/vibe-studio@beta
```

After the beta package is published, this command starts the local web application. See the [getting started guide](/getting-started) for setup.
