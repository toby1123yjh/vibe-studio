---
title: "OpenCode"
description: "Use your locally installed OpenCode agent in sessions and workflows"
---

Vibe Studio launches your installed `opencode acp` executable. You can use
OpenCode in ordinary sessions, workflow Nodes and the workflow's main Agent.
Its native configuration, tools and session history remain owned by OpenCode.

## Install and configure

Install OpenCode from the Agent page, or use its official npm package:

```bash
npm install --global opencode-ai
```

Configure your chosen model provider using
[OpenCode's authentication instructions](https://opencode.ai/docs/providers/).
OpenCode supports multiple model providers; installing its executable does not
configure every provider's credentials.

If you install it manually, rescan the host on Vibe Studio's Agent page. The
server process must be able to find `opencode` on its PATH. Use a command
override for a custom executable path. Vibe Studio does not pin a runtime version
or download a replacement CLI when you start a session.

## Native assets

OpenCode uses JSON/JSONC configuration under `~/.config/opencode` by default
and project `opencode.json` or `opencode.jsonc` files. Native settings can be
overridden by XDG paths, OpenCode environment variables and managed policies.

Its MCP servers use the `mcp` configuration section and native `enabled`
switches. Skills use `SKILL.md` bundles; reusable commands use Markdown or
native configuration entries. Copying a remote MCP definition does not transfer
its OAuth login or tokens.

## Protocol limits

Sessions created through Vibe Studio can continue using their native session
ID. Importing arbitrary existing OpenCode history into Vibe Studio is not yet
supported.

Model and reasoning choices use options advertised by your installed CLI.
Session continuation prefers native resume without replaying historical
messages. If the installed version supports only load, Vibe Studio suppresses
old transcript updates before sending your new prompt.

<Note>
  Not every terminal feature is exposed over ACP. OpenCode's built-in `/undo`
  and `/redo` are not supported through this integration. See the [official ACP
  documentation](https://opencode.ai/docs/acp/) for native limits.
</Note>
