---
title: "Oh My Pi"
description: "Set up the Oh My Pi coding agent"
---

Oh My Pi is integrated as an external `omp` runtime over its stdio RPC
protocol. Vibe Studio keeps the provider-native session and protocol records
separate from the canonical conversation timeline.

<Steps>
<Step title="Install Oh My Pi">
  ```bash
  npm install --global @oh-my-pi/pi-coding-agent
  ```

  This installs the `omp` executable that Vibe Studio launches from your PATH.
  Keep Oh My Pi updated independently; Vibe Studio does not bundle or pin its
  runtime version.
</Step>

<Step title="Follow the login instructions">
  Complete the authentication flow provided by Oh My Pi. See the
  [Oh My Pi repository](https://github.com/can1357/oh-my-pi) for current
  installation and authentication details.
</Step>

<Step title="Start Vibe Studio">
  Once authenticated, launch Vibe Studio:

  ```bash
  npx @toby1123yjh/vibe-studio@beta
  ```

  You can now select Oh My Pi when creating task attempts.
</Step>
</Steps>

<Info>
Vibe Studio invokes the real `omp --mode rpc` executable. It does not embed a
Node SDK or replace Oh My Pi's native tools, MCP servers, or subagent model.
</Info>
