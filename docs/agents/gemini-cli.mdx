title: "Gemini CLI"
description: "Set up Google Gemini CLI"

---

<Steps>
<Step title="Install Gemini CLI">
  ```bash
  npm install --global @google/gemini-cli
  ```

  Vibe Studio launches the `gemini` command from your PATH. Keep the CLI
  updated independently; Vibe Studio does not bundle or pin a Gemini CLI
  runtime version.
</Step>

<Step title="Follow the login instructions">
  Complete the authentication flow as prompted. For more details, see [geminicli.com](https://geminicli.com/).
</Step>

<Step title="Start Vibe Studio">
  Once authenticated, launch Vibe Studio:

  ```bash
  npx vibe-studio@beta
  ```

  You can now select Gemini CLI when creating task attempts.
</Step>
</Steps>
