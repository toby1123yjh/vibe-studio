## 当前要做什么

让多个 Agent 通过项目文件接力完成一件业务工作：节点输出拆分任务，主 Agent 阅读并分配给已有执行节点，Runtime 负责串行/并行执行、汇总、停止和恢复。

本次 P0 已于 2026-10-14 收口。文件交接、拆分分工、批次调度和页面已实现；定向自动回归及 Codex / Claude Code 的普通文件接力、自动分工、串并行、停止和精确汇总重试已通过，文件与原生审计均已核验。按用户确认，不再追加扩展实机场景作为本任务的完成条件；已测与未测范围如实保留在[实施与验收计划](./implement.mdx)。

## 这次的闭环

```text
需求与材料文件
      ↓
拆分节点 → 任务清单和说明文件
      ↓
主 Agent → 分工文件（仅分配给已配置的固定节点）
      ↓
Runtime → 阶段之间串行、阶段内部并行
      ↓
执行节点 → 成果和交接文件 → 汇总交付
```

普通工作流即使没有拆分节点，也要支持文件交接。拆分子任务不是 VB 看板业务任务；文件传递工作内容，Runtime 与数据库记录真实状态，改文件不等于启动执行或宣告成功。
